# Machine Learning for Portfolio Optimisation

A comprehensive quantitative finance and machine learning framework for:

- Portfolio Optimisation
- Risk Management
- Asset Allocation
- Return Forecasting
- Backtesting
- Reinforcement Learning Strategies

## Features

### Portfolio Optimisation
- Mean-Variance Optimisation
- Black-Litterman Model
- Risk Parity
- CVaR Optimisation
- Efficient Frontier

### Machine Learning Models
- Linear Regression
- Random Forest
- XGBoost
- LSTM Networks
- Reinforcement Learning

### Risk Analytics
- Value at Risk (VaR)
- Conditional VaR
- Monte Carlo Simulation
- Stress Testing

### Backtesting
- Transaction Costs
- Performance Metrics
- Sharpe Ratio
- Sortino Ratio
- Drawdown Analysis
